Run phase **P3 — Planning & Backlog** for: **$ARGUMENTS**

1. Delegate to `requirements-analyst`: break down & refine stories, detect cross dependencies.
2. Delegate to `test-engineer`: draft the test strategy (unit/SIT/UAT/perf/security) and the test data plan (masked/synthetic).
3. Check the **Definition of Ready** for each story (clear requirements, data classified, security impact assessed, estimated, deterministic test approach).
4. Update state (current_phase: plan).

There is no hard gate at P3, but only stories that meet the DoR should enter the sprint.
